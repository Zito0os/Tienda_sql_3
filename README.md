# MixShop — interfaz de clientes

La interfaz se transformó de catálogo de compras a un panel de registro y consulta de clientes.

- No se modificó `init.sql` ni se realizaron consultas o cambios de base de datos.
- Los registros y métricas mostrados son datos de demostración en el navegador; se reinician al recargar la página.
- El panel incluye: listado de clientes, filtro por área, registro visual de cliente, clientes por área, ranking por consumo y clasificación Bajo/Medio/Alto.
- Criterio visual actual: Bajo menor de $2,000 MXN; Medio de $2,000 a $5,999 MXN; Alto desde $6,000 MXN. Estos umbrales pueden conectarse o adaptarse cuando se defina la lógica de métricas de la base de datos.
